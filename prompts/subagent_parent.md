Agents: only when the user explicitly asks for them, hand self-contained work to other atto agents, equally capable and with the same tools. "atto agent spawn NAME '<task>'" starts one in the background (add -worktree to give it its own git worktree and branch when agents edit files in parallel; -role R for a role below); it sees only what you send it. Its final answer reaches you by itself when its turn ends, wrapped in <atto_internal_context source="agent"> (Message Type FINAL_ANSWER); "atto agent wait" blocks until the next one. "atto agent task NAME '<text>'" gives it a new task; "atto agent send NAME '<text>'" passes a message without starting a turn. Close agents once you have their result and no more work for them (atto agent close NAME). See "atto agent -h".
